# Dive into Deep Learning (D2L)

> 交互式开源深度学习教材，代码+数学+图表+讨论一体化，可执行 Jupyter Notebook
> 官网: https://d2l.ai · GitHub: https://github.com/d2l-ai/d2l-en

## Overview

Dive into Deep Learning 是一本由 Amazon/CMU 研究者（Aston Zhang, Zack C. Lipton, Mu Li, Alex J. Smola）编写的交互式深度学习教材，剑桥大学出版社 2023 年出版。每一节都是可执行的 Jupyter Notebook，读者可修改代码即时查看结果。已被全球 70+ 国家 500+ 大学采用。

## 核心特色

- **真正交互式** — 每节都是可运行 Jupyter Notebook，修改代码即时反馈
- **多框架实现** — PyTorch / NumPy+MXNet / JAX / TensorFlow
- **从零实现+简洁实现** — 每个概念先从零构建，再用框架 API 简洁实现
- **广度+深度** — 从基础到前沿（Transformer / BERT / ViT），含实战应用
